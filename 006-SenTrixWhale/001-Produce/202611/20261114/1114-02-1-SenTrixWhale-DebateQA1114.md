### A2. 「本地 0 元」和 12.78 元并列，对比不对称

1. 本地 Qwen 的 API 调用费是 0，但电费、硬件折旧、GPU 占用都在；

**周汇报里不做两者成本对比。**

### A3. 120 / 135 是什么意思？

- 分母 135 = 同源回归集规模
- 分子 120 = 描述基本准确的数量
- 89 分 = 相对 DSAPI 基准的得分

**执行建议：小稿删除这组数字。** 两页版解释不了分母/基准/评分维度，留着只会被追问。
