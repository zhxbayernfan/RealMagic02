快速调用

先检查服务健康状态和可用模型。健康接口返回 HTTP 200，响应体可以为空。

curl --noproxy 192.168.0.118 -i --max-time 10 http://192.168.0.118:8104/health
curl --noproxy 192.168.0.118 --max-time 10 http://192.168.0.118:8104/v1/models

发送文字对话：

curl --noproxy 192.168.0.118 --max-time 240 http://192.168.0.118:8104/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen35-mixed-3p1",
    "messages": [
      {"role": "system", "content": "请用简洁的中文回答。"},
      {"role": "user", "content": "17乘以19等于多少？只输出结果。"}
    ],
    "temperature": 0,
    "max_tokens": 128,
    "chat_template_kwargs": {"enable_thinking": false}
  }'

结果在 choices[0].message.content 中；usage 提供 token 用量，finish_reason="stop" 表示正常结束，"length" 表示达到输出长度限制。

curl 流式调用：在上面的 JSON 中添加 "stream": true，并给 curl 添加 -N。响应为 SSE，每个 data: JSON 事件的文本在 choices[0].delta.content，以 data: [DONE] 结束。

普通对话

from openai import OpenAI
import httpx

client = OpenAI(
    base_url="http://192.168.0.118:8104/v1",
    api_key="EMPTY",
    timeout=240.0,
    max_retries=0,
    http_client=httpx.Client(trust_env=False),
)
response = client.chat.completions.create(
    model="qwen35-mixed-3p1",
    messages=[
        {"role": "system", "content": "请用简洁的中文回答。"},
        {"role": "user", "content": "介绍一下你自己。"},
    ],
    temperature=0.7,
    max_tokens=256,
    extra_body={"chat_template_kwargs": {"enable_thinking": False}},
)
print(response.choices[0].message.content)
print(response.usage)

流式输出

复用上面的 client：

stream = client.chat.completions.create(
    model="qwen35-mixed-3p1",
    messages=[{"role": "user", "content": "用一句话解释什么是大语言模型。"}],
    temperature=0.7,
    max_tokens=128,
    stream=True,
    extra_body={"chat_template_kwargs": {"enable_thinking": False}},
)
for chunk in stream:
    if chunk.choices:
        text = chunk.choices[0].delta.content
        if text:
            print(text, end="", flush=True)
print()

Agent 自动工具调用

服务已配置 --enable-auto-tool-choice --tool-call-parser qwen3_coder。请求可以携带 tools 和 tool_choice="auto"，无需修改 Base URL 或模型名。本权重的 chat template 使用 Qwen 的 XML 函数格式，由服务转换成 OpenAI 格式的 tool_calls。

模型负责选择工具并生成参数，实际工具由客户端执行。客户端收到工具调用后，将原 assistant 消息和对应的 role="tool" 结果一起加入历史，再请求模型生成最终回答。tool_call_id 必须匹配返回的调用 ID。

以下复用上面的 client。库存查询使用本地固定数据演示完整往返，接入业务时替换为真实工具实现。

import json

tools = [{"type": "function", "function": {
    "name": "lookup_inventory",
    "description": "Look up current inventory. Always use for stock questions.",
    "parameters": {
        "type": "object",
        "properties": {"item_code": {"type": "string"}},
        "required": ["item_code"],
        "additionalProperties": False,
    },
}}]
messages = [
    {"role": "system", "content": "必须查询工具后回答库存，不要编造。"},
    {"role": "user", "content": "请查询 SKU-418 当前有多少库存。"},
]
options = dict(
    model="qwen35-mixed-3p1",
    tools=tools,
    tool_choice="auto",
    temperature=0,
    max_tokens=192,
    extra_body={"chat_template_kwargs": {"enable_thinking": False}},
)
first = client.chat.completions.create(messages=messages, **options)
message = first.choices[0].message
if not message.tool_calls:
    raise RuntimeError(f"模型没有调用工具：{message.content}")
messages.append({
    "role": "assistant",
    "content": message.content,
    "tool_calls": [call.model_dump() for call in message.tool_calls],
})
for call in message.tool_calls:
    if call.function.name != "lookup_inventory":
        raise ValueError("未知工具")
    args = json.loads(call.function.arguments)
    inventory = {"SKU-418": 37}  # 本地演示数据
    result = {"item_code": args["item_code"], "stock": inventory[args["item_code"]]}
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps(result, ensure_ascii=False),
    })
final = client.chat.completions.create(messages=messages, **options)
print(final.choices[0].message.content)

正常工具调用的 finish_reason 为 tool_calls，参数位于 choices[0].message.tool_calls[].function.arguments，类型是 JSON 字符串。流式调用需按 delta.tool_calls[].index 拼接函数名和参数，收齐后再解析 JSON。传入工具但希望禁止调用时可设置 tool_choice="none"。

工具定义和工具结果也计入 4096 token 上下文预算。实际 Agent 应限制工具循环轮数，并检查最终响应是否仍包含新的 tool_calls。

格式参考：vLLM Qwen3.5 工具调用配置；本机采用已安装的 qwen3_coder，并保持原有 chat template。

单张图片问答

把调用电脑上的图片编码为 data URL 发送，服务端无需访问调用电脑的文件路径。下面复用上一节的 client，支持常见 PNG、JPEG、WebP 图片。

import base64
import mimetypes
from pathlib import Path

image = Path("example.png")
mime = mimetypes.guess_type(image.name)[0] or "image/png"
data = base64.b64encode(image.read_bytes()).decode("ascii")
response = client.chat.completions.create(
    model="qwen35-mixed-3p1",
    messages=[{
        "role": "user",
        "content": [
            {"type": "image_url", "image_url": {
                "url": f"data:{mime};base64,{data}"
            }},
            {"type": "text", "text": "请描述图片中的主要内容。"},
        ],
    }],
    temperature=0,
    max_tokens=256,
    extra_body={"chat_template_kwargs": {"enable_thinking": False}},
)
print(response.choices[0].message.content)

也可使用 image_url.url 传入 Orin 可以访问的 HTTP/HTTPS 图片地址；本次验收使用 base64 图片。每次请求最多一张图片，当前配置不接收视频。图片由处理器按约 262144 像素预算缩放，较小的文字和细节可能受影响。

参数与部署限制

项目当前配置
上下文4096 token，包含消息模板、历史消息、图像 token 和输出；max_tokens 应小于剩余空间。
并发最多同时调度 2 个序列；更多请求排队，共享缓存不足时也可能等待。建议业务侧并发不超过 2。
生成模式默认关闭思考，普通自回归解码；未启用 MTP 推测解码。示例也显式关闭思考。
Agent 工具调用启用自动工具选择，parser 为 qwen3_coder；支持普通和流式 tool_calls，工具由客户端执行。
采样每次请求显式填写 temperature；确定性检查用 0，常规对话可从 0.7 开始。
长度每次显式填写 max_tokens，建议先用 128～512；其含义是最多生成多少 token。
图片1 张 / 请求，处理像素预算 262144；视频数量上限为 0。
KV/cache 预算1 GiB，显式指定；这不是整个服务的总内存上限。
计算精度FP16，eager 模式；无前缀缓存。
运行环境Jetson AGX Orin 64GB，JetPack R36.4.7 / CUDA 12.6；vLLM 0.19.0+cu126，PyTorch 2.10.0，Transformers 5.5.0。

权重目录中的 safetensors 是原混合量化 GGUF 的 FP32 反量化展开版，加载时转成 FP16，仍保留原量化误差。目录名中的 3p1 不代表此 vLLM 服务按 3.1bit kernel 运行。

现象处理
连接拒绝或超时先从调用电脑访问 /health；检查两台机器网络、IP 和容器状态。启动期间需等待模型加载与预热完成，首次冷启动可能需要数分钟。
客户端 HTTP 502，但 curl 可以访问检查系统或环境变量代理是否转发了局域网请求。Python 示例已用 trust_env=False 直连；其他客户端将 192.168.0.118 加入代理绕过名单，curl 可添加 --noproxy 192.168.0.118。
HTTP 400，上下文超限缩短历史消息、图片内容或 max_tokens，使总长度不超过 4096 token。
HTTP 404，模型不存在模型名须为 qwen35-mixed-3p1，通过 /v1/models 核对。
内容被截断检查 finish_reason；若为 length，在剩余上下文允许时增加 max_tokens。
响应慢或内存错误减少业务并发并检查 Orin 上其他模型的占用；查看容器日志。该机器共享内存与其他服务，响应耗时随负载变化。
