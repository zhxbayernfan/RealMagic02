# 人脸识别模型调研报告

## 基本信息
本次横向对比了4个模型。InsightFace buffalo_l 在轻量化和部署便捷性上优势明显,作为FMA主方案无需争议。此外,其他模型中表现最好的是DeepFace系列,以下为具体测试数据。
- 调研周期: 2026-07-28 ~ 2026-07-31
- 测试机器: 192.168.0.200 (Ubuntu, GPU3090-24G)
- 测试集: 5张照片, 8个人脸 (蔡老师合影/宋老师合影/校徽/2017广州塔/2020圆明园)
- 评测模型: InsightFace buffalo_l / DeepFace (ArcFace / Facenet)

## 一、模型简介

### InsightFace buffalo_l
- 维护方: DeepInsight (开源)
- 模型形态: 5个onnx文件, 共325MB
- 包含: 检测(det_10g) + 关键点(2d106det) + 对齐(1k3d68) + 识别(w600k_r50/ArcFace) + 年龄性别(genderage)
- 安装方式: `pip install insightface`, 首次自动下载权重

### DeepFace
- 维护方: serengil (开源)
- 模型形态: Python包, 依赖TensorFlow (~1.5GB)
- 包含: 检测(可选opencv/mtcnn/retinaface) + 识别(可选VGG-Face/Facenet/Facenet512/ArcFace/Dlib) + 年龄性别
- 安装方式: `pip install deepface`, 自动安装TensorFlow, 首次调用时下载权重
- 测试中遇到的问题: opencv-haarcascade依赖冲突, 模型权重巨大(Facenet 539MB, VGG-Face 550MB), 下载受网络限制

## 三、综合对比

|维度|InsightFace buffalo_l|DeepFace|
|--|--|--|
|**安装体积**|325MB (一站式完整体)|>2.5GB (基础+TF, 每加一个模型约+500MB)|
|**检测速度(CPU)**|**0.21s/张**|0.08~0.32s/张 (ArcFace+opencv)|
|**识别精度**|同一人>0.67(同一年份), 跨年份~0.4<br>不同人<0.05|ArcFace: 4组比对中2组正确匹配|
|**年龄性别**|✅ 自带, 性别准确年龄偏差较大|✅ 自带, 性别准确, 年龄偏差比buffalo_l更大|
|**GPU加速**|可选(onnxruntime-gpu/CPU)|需TensorFlow GPU版, 环境更复杂|
|**离线使用**|✅ 一次下载后全离线|⚠️ 需下载模型权重(首次数小时)|
|**安装难度**|⭐ 简单, pip install|⭐⭐⭐⭐ 依赖TF, 版本冲突多|
|**社区活跃度**|高 (DeepInsight)|高 (serengil)|
|**多模型支持**|单一模型包, 自带ArcFace|支持6种识别模型+3种检测器, 灵活但体积大|

## 四、DeepFace部署成本

1. 环境依赖: 需要opencv-python + TensorFlow + tf-keras等多层依赖, 与FMA现有环境存在版本兼容问题
2. 模型权重: Facenet 539MB, VGG-Face ~550MB, 加上TF 1.5GB, 总计>2.5GB
3. 首次部署: 需额外下载模型权重, 网络依赖较重

## 五、结论

**推荐继续使用 InsightFace buffalo_l**, 理由:

1. ✅ **精度够用**: 同一人>0.67, 不同人<0.05, 区分度清晰
2. ✅ **轻量部署**: 325MB, 无需额外依赖, 与FMA环境无冲突
3. ✅ **离线可用**: 一次下载后全离线, 不受200机器网络限制
4. ✅ **速度可接受**: 0.23s/张(CPU), 当前场景下够用
5. ✅ **一站式**: 检测+识别+年龄+性别, 一套搞定

**DeepFace不建议引入**, 原因:

1. ❌ 环境冲突: TF + opencv + onnxruntime 在同一环境版本冲突严重
2. ❌ 体积过大: >2.5GB, 是buffalo_l的7.7倍
3. ❌ 网络依赖: 模型权重539MB+, 首次下载数小时
4. ❌ 性价比低: 同样的ArcFace算法, buffalo_l已内建且精度更高, 无需额外安装
